## 1. 项目背景与目标

本系统面向关注中国 A 股市场的个人投资者和小型研究团队，目标是提供一个工程化、可运行的股票数据服务与分析平台，结合 AkShare 获取行情与基本面数据，提供技术指标、投资组合管理、实时推送与 AI 辅助问答。

主要目标：

- 稳定提供 A 股实时与历史行情查询（基于 AkShare）
- 提供常用技术指标计算、涨跌榜与行业板块数据
- 支持用户级投资组合与自选股管理（持仓、收益计算）
- 提供基于规则与模板的 AI 聊天辅助（可扩展到调用外部 LLM）
- 支持实时数据推送（Socket.IO）与定时任务/批量抓取工具

## 2. 与仓库实现一致的技术概览

- 后端：Python + Flask（应用工厂），入口文件 `project/backend/app.py`、`run.py`
- 行情数据：AkShare（`app/services/stock_data.py`）
- 实时通信：Flask-SocketIO（`app/websocket/events.py`）
- 认证：Flask-JWT-Extended（`app/api/auth.py`）
- ORM：SQLAlchemy（`app/models/*.py` 包含 User/Portfolio/WatchList 等模型）
- AI 聊天：内置规则/模板聊天服务（`app/services/ai_chat.py`），由 `app/api/ai_chat.py` 暴露接口
- 工具脚本：`project/backend/tools/` 包含实时/历史/基本面/分析等辅助脚本
- 任务调度：`app/tasks/scheduler.py`（示例中有 Celery/定时任务相关代码）

## 3. 已实现的核心功能（代码级别）

下面按模块列出仓库中已有的功能，便于文档与开发对齐：

3.1 股票与市场数据（`app/services/stock_data.py`, `app/api/stocks.py`, `app/api/market.py`）

- 搜索股票（代码/名称）
- 查询单只股票的实时基本信息
- 查询股票历史行情（daily/weekly/monthly）
- 计算并返回常用技术指标（MA、RSI、成交量比等）
- 获取热门股票（涨幅榜、成交量榜、换手率榜等）
- 获取市场指数、行业板块及市场概览
- 提供市场新闻与财经日历的抓取（AkShare 支持时）

3.2 投资组合与自选股（`app/api/portfolio.py`, `app/models/portfolio.py`, `app/models/watchlist.py`）

- 用户可创建/更新/删除投资组合（JWT 保护）
- 投资组合内可添加/更新/删除持仓，系统会尝试获取当前价格用于估值
- 支持自选股列表（WatchList）：创建/添加/删除股票

3.3 用户认证与用户信息（`app/api/auth.py`, `app/api/user.py`）

- 用户注册、登录、刷新令牌、获取用户信息等基本认证功能

3.4 实时推送（`app/websocket/events.py`）

- 基于 Socket.IO 的订阅机制：客户端可 subscribe/ unsubscribe 特定股票或市场频道
- 服务器可推送实时行情或聚合市场数据给订阅客户端

3.5 AI 聊天助手（`app/services/ai_chat.py`, `app/api/ai_chat.py`）

- 基于规则和模板的自然语言理解：识别股票代码（6位数字）、板块关键词等
- 能响应市场查询、股票分析请求、投资建议模板与风险评估提示
- 返回包含建议、来源（实时数据或指标）与置信度的结构化回复

3.6 辅助工具与脚本（`project/backend/tools/`）

- `realtime_data_service.py`：用于批量拉取或持久化实时行情的脚本/服务
- `historical_data_service.py`：历史数据抓取与格式化
- `fundamental_data_service.py`：基础财务数据抓取（AkShare/其它渠道）
- `market_analysis_service.py`、`stock_analysis_system.py`：市场/股票层面的分析封装
- `data_cache_manager.py`：示例缓存管理工具

## 5. 已知实现细节与限制

- AkShare 依赖：AkShare 是本项目行情和部分数据的主要来源。AkShare 调用在仓库中有重试与超时包装，但仍可能因源站变化或网络问题导致功能受限。
- 缓存：代码中对缓存（Redis）的引用存在，但在 `stock_data` 中默认以进程内简短缓存为主；建议生产环境启用 Redis 并完善缓存策略。
- AI 能力：当前 `ai_chat` 为规则/模板驱动，非直接调用 Claude/OpenAI。若要使用外部 LLM，需要实现客户端与配额、成本管理逻辑。
- 并发与速率：大量实时订阅和频繁 AkShare 请求可能造成性能与外部接口压力，建议采用批量拉取、限流与缓存层。

## 6. 快速运行（开发）

1. 建议使用虚拟环境并安装依赖：

```powershell
python -m venv .venv; .\.venv\Scripts\Activate.ps1; pip install -r project\backend\requirements_simple.txt
```

2. 复制并编辑环境变量：

```powershell
copy project\backend\.env.example project\backend\.env
# 编辑 project\backend\.env，设置 DATABASE_URL, REDIS_URL 等
```

3. 启动服务（开发）：

```powershell
cd project\backend
python run.py
```

4. （可选）运行工具脚本：

```powershell
python project\backend\tools\realtime_data_service.py
```
