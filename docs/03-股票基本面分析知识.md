# 股票基本面分析知识

## 1. 基本面分析概述

### 1.1 基本面分析定义
基本面分析是通过研究影响股票价值的经济、金融因素来评估股票内在价值的方法。主要包括：
- **宏观经济分析**：经济环境对股票市场的影响
- **行业分析**：行业发展趋势和竞争格局
- **公司分析**：公司财务状况和经营能力

### 1.2 分析目标
- 确定股票的内在价值
- 判断股票是否被高估或低估
- 预测公司未来盈利能力
- 评估投资风险和回报

## 2. 财务报表分析

### 2.1 三大财务报表

#### 2.1.1 资产负债表
**作用**：反映公司某一时点的财务状况
**关键指标**：
- **总资产**：公司拥有的全部资源
- **总负债**：公司承担的全部债务
- **股东权益**：股东在公司中的权益
- **流动资产/负债**：一年内变现/偿还的资产/负债

#### 2.1.2 利润表（损益表）
**作用**：反映公司一定期间的经营成果
**关键指标**：
- **营业收入**：公司主营业务收入
- **营业成本**：为获得收入而发生的直接成本
- **净利润**：扣除所有费用后的最终利润
- **每股收益(EPS)**：净利润/流通股数

#### 2.1.3 现金流量表
**作用**：反映公司现金流入流出情况
**关键指标**：
- **经营活动现金流**：主营业务产生的现金流
- **投资活动现金流**：投资相关的现金流
- **筹资活动现金流**：融资相关的现金流
- **自由现金流**：可供股东分配的现金

  ## 1. 快速结论（要点速览）
  - 优先看质量：经营活动现金流（OCF）与扣非净利润是第一信号。
  - ROE 高要看来源：利润率、周转或杠杆哪个在驱动？用杜邦拆解。
  - 长期正向自由现金流（FCF）+稳定ROIC 才是真正的护城河表现。
  - 高成长公司若没有正向 FCF，需要重点观察资本开支回报率与融资可持续性。

  ## 2. 核心分析思路与流程（肖星式三步法）
  步骤 1：快速筛查（质量筛查）
  - 是否有正的经营现金流？扣非后净利润是否为正并持续？
  - 是否有异常一次性收益或大额关联交易？

  步骤 2：来源分解（杜邦与结构化分析）
  - 通过 ROE = 净利率 × 总资产周转率 × 权益乘数，判断盈利是业务驱动还是杠杆驱动。

  步骤 3：价值判断（估值与风险对比）
  - 在质量可接受时，用 PE/PEG/DCF 等判断估值；若质量差，低估值也可能是陷阱。

  ## 3. 报表与关键概念（速查）
  - 资产负债表：静态的财务结构与杠杆水平（关注总负债、流动比率、权益乘数）。
  - 利润表：盈利能力与利润来源（主营、投资、非经常性收益）。
  - 现金流量表：经营现金流（OCF）、投资现金流与筹资现金流；自由现金流是最重要的衡量现金创造能力的指标。

  ## 4. 财务质量优先：经营现金流与扣非利润
  - 经营活动现金流（OCF）与净利润比 = OCF / 净利润（近3年均值），若远低于1或为负需警惕盈利质量问题。
  - 扣非净利润占比（净利润 − 非经常性损益）用于去除偶发项对利润的影响。
  - 检查应收账款与存货的增速是否合理，是否有大额应收或存货积压。

  实操建议：优先在数据中计算近 3 年的 OCF、净利润、FCF 和非经常性损益比重，并在报告中突出显示异常年份与变化率。

  ## 5. 盈利能力与杜邦分解（ROE 分析）
  - 公式：ROE = 净利率 × 总资产周转率 × 权益乘数
    - 净利率 = 净利润 / 营业收入
    - 总资产周转率 = 营业收入 / 平均总资产
    - 权益乘数 = 总资产 / 股东权益

  分析要点：
  - 如果 ROE 上升是因权益乘数增加（杠杆上升），需判断债务与利息负担是否可持续。
  - 如果 ROE 下降且是净利率拖累，需查看毛利率/费用率变化及主营业务问题。

  ## 6. 偿债与杠杆分析
  - 关键指标：资产负债率、流动比率、速动比率、利息保障倍数（EBIT/利息费用）。
  - 关注短期偿债（1年内到期债务）与现金/短期投资覆盖能力。

  预警规则示例：利息保障倍数 < 3 或 流动比率 < 1 → 列入风险观察名单。

  ## 7. 营运效率与周转指标
  - 应收账款周转天数 = 365 /（营业收入 / 平均应收账款）
  - 存货周转天数 = 365 /（营业成本 / 平均存货）
  - 固定资产周转率 = 营业收入 / 平均固定资产

  判断要点：横向对比行业、纵向看趋势，若天数持续上升说明资金回收变慢或需求下滑。

  ## 8. 成长性与资本回报（ROIC）
  - ROIC = NOPAT / 投入资本（NOPAT = 税后营业利润）
  - 判断公司是否以高于资本成本的回报率投入资本，长期 ROIC > WACC 才可认为投资有效。

  成长质量判断：增长是否由营业收入扩张驱动，还是通过大规模借债/摊薄股权实现？

  ## 9. 估值框架（相对估值 + DCF 实务要点）
  相对估值：PE / PB / PS / PEG，注意行业可比与周期性调整

  DCF 快速要点：
  - 优先使用保守假设（长期增长率 g 保守估计），并做情景分析（乐观/基线/悲观）
  - 将预测期分短期（3-5 年）+ 永续期（终值），计算 WACC 时需注意资本结构与本币风险溢价

  估值陷阱提示：高 PE 配合低/负 FCF 或临时性利润需谨慎

  ## 10. 风险识别与预警信号
  - 经营：主营业务收入下降、毛利率下滑、客户集中度高
  - 现金：连续负 OCF、FCF 为负且无明确回正计划
  - 财务：快速上升的短期借款、利息保障倍数下降
  - 会计/治理：频繁调整会计政策、重大关联交易或高比例非经常性损益

  ## 11. 决策模板与评分体系（便于自动化）
  建议用评分卡（示例，满分100）：
  - 财务质量（30 分）：OCF/净利润、扣非占比、现金覆盖率
  - 盈利能力（20 分）：ROE、净利率
  - 偿债安全（15 分）：流动比率、利息保障倍数
  - 成长性（15 分）：营收/净利 3 年复合增长率
  - 估值与拍卖（10 分）：PE vs 行业、PEG
  - 公司治理（10 分）：独立董事、关联交易披露

  得分区间示例：
  - ≥75：优质（长期关注）
  - 50-75：观望/择优介入
  - <50：回避或仅短线关注

  ## 12. 指标实现与自动化（如何在系统中落地）
  1) 数据采集：使用 `project/backend/tools/fundamental_data_service.py` 或 AkShare 抓取财报、经营数据并落入数据库（或时序/表格存储）。
  2) 指标计算：新增 `app/services/financial_analysis.py`，接口例如：
     - `GET /api/v1/analysis/financial/{symbol}` 返回历年关键指标、杜邦分解、预警标记与评分
  3) 定时任务：用 `app/tasks/scheduler.py` 定期计算并缓存关键指标与预警（每天/每季度）
  4) 展示：在股票详情页显示 3 年趋势图、评分卡和预警日志；AI 聊天模块可引入该接口生成自然语言摘要

  ## 13. 附：常用公式与示例
  - ROE = 净利润 / 平均股东权益
  - ROA = 净利润 / 平均总资产
  - 净利率 = 净利润 / 营业收入
  - 毛利率 =（营业收入 − 营业成本）/ 营业收入
  - 自由现金流 FCF = 经营活动现金流 − 资本支出
  - 权益乘数 = 总资产 / 股东权益（用于杜邦）
  - 利息保障倍数 = EBIT / 利息费用
