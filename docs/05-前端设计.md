# 前端设计文档 - UI/UX规范与交互设计

## 1. 设计系统概览

### 1.1 设计理念
- **简洁高效**：专业的金融数据展示，避免过度装饰
- **数据驱动**：以数据可视化为核心的界面设计
- **响应式设计**：适配桌面、平板、移动端
- **用户体验优先**：快速访问核心功能，减少操作步骤

### 1.2 技术栈
- **框架**: React 18 + TypeScript
- **状态管理**: Redux Toolkit / Zustand
- **UI组件库**: Ant Design / Material-UI
- **图表库**: ECharts / TradingView
- **样式方案**: Styled-components / Tailwind CSS
- **构建工具**: Vite / Create React App

### 1.3 设计系统架构
```
前端架构 (响应式设计)
├── 页面布局层
│   ├── 响应式栅格系统
│   ├── 导航系统
│   └── 侧边栏/抽屉组件
├── 组件库
│   ├── 基础组件 (Button, Input, Card等)
│   ├── 业务组件 (StockCard, ChartContainer等)
│   └── 复合组件 (DataTable, Dashboard等)
├── 数据可视化层
│   ├── 图表组件 (K线图, 柱状图, 饼图)
│   ├── 指标展示 (仪表盘, 进度条)
│   └── 实时数据流 (WebSocket集成)
├── 交互设计层
│   ├── 手势操作 (图表缩放, 滑动)
│   ├── 快捷键支持
│   └── 搜索与筛选
└── 主题系统
    ├── 明亮主题 (默认)
    ├── 深色主题
    └── 高对比度主题 (无障碍)
```

### 7.2 主题切换
```tsx
// 主题切换组件
const ThemeToggle: React.FC = () => {
  const { theme, toggleTheme } = useTheme();

  return (
    <button
      onClick={toggleTheme}
      className="theme-toggle"
      aria-label="切换主题"
    >
      {theme === 'light' ? '🌙' : '☀️'}
    </button>
  );
};

// 主题持久化
const useTheme = () => {
  const [theme, setTheme] = useState<'light' | 'dark'>(() => {
    // 优先级: localStorage > 系统偏好 > 默认
    const stored = localStorage.getItem('theme');
    if (stored) return stored as 'light' | 'dark';

    const systemDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
    return systemDark ? 'dark' : 'light';
  });

  const toggleTheme = useCallback(() => {
    const newTheme = theme === 'light' ? 'dark' : 'light';
    setTheme(newTheme);
    localStorage.setItem('theme', newTheme);
  }, [theme]);

  return { theme, toggleTheme };
};
```
