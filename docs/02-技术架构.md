# 技术架构

## 1. 系统架构概览

### 1.1 整体架构
```
┌─────────────────────────────────────────────────────────────┐
│                        用户界面层                              │
│                     (Vue.js前端)                            │
├─────────────────────────────────────────────────────────────┤
│                        业务逻辑层                              │
│                     (Python后端)                            │
├─────────────────────────────────────────────────────────────┤
│                        AI服务层                               │
│                     (Claude Agent)                          │
├─────────────────────────────────────────────────────────────┤
│                        数据服务层                              │
│                  (数据库 + 外部API)                           │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 架构特点
- **分层架构**：清晰的层次结构，便于维护和扩展
- **微服务化**：各模块独立部署，提高系统可用性
- **AI驱动**：Claude AI作为核心分析引擎
- **数据导向**：实时数据获取和处理

## 2. 前端架构

### 2.1 技术栈
- **框架**：Vue.js 3.x
- **UI库**：Element Plus / Ant Design Vue
- **状态管理**：Pinia
- **路由**：Vue Router
- **HTTP客户端**：Axios
- **图表库**：ECharts / Chart.js
- **构建工具**：Vite

### 2.2 目录结构
```
frontend/
├── src/
│   ├── components/          # 通用组件
│   │   ├── StockChart/      # 股票图表组件
│   │   ├── DataTable/       # 数据表格组件
│   │   └── AnalysisCard/    # 分析卡片组件
│   ├── views/               # 页面组件
│   │   ├── Dashboard/       # 仪表盘
│   │   ├── StockAnalysis/   # 股票分析
│   │   ├── Portfolio/       # 投资组合
│   │   └── Settings/        # 设置页面
│   ├── store/               # 状态管理
│   │   ├── modules/
│   │   │   ├── stock.js     # 股票数据状态
│   │   │   ├── user.js      # 用户状态
│   │   │   └── analysis.js  # 分析结果状态
│   │   └── index.js
│   ├── api/                 # API接口
│   ├── utils/               # 工具函数
│   ├── assets/              # 静态资源
│   └── router/              # 路由配置
└── public/
```

### 2.3 核心功能模块
- **数据可视化**：股票价格走势图、技术指标图表
- **分析展示**：基本面分析结果、技术面分析报告
- **交互操作**：股票搜索、参数配置、数据筛选
- **用户管理**：登录注册、个人设置、偏好配置

## 3. 后端架构

### 3.1 技术栈
- **语言**：Python 3.9+
- **框架**：FastAPI / Django
- **数据库**：PostgreSQL / MySQL
- **缓存**：Redis
- **任务队列**：Celery
- **Web服务器**：Uvicorn / Gunicorn
- **API文档**：Swagger / OpenAPI

### 3.2 目录结构
```
backend/
├── app/
│   ├── api/                 # API路由
│   │   ├── v1/
│   │   │   ├── stock.py     # 股票相关API
│   │   │   ├── analysis.py  # 分析相关API
│   │   │   ├── user.py      # 用户相关API
│   │   │   └── portfolio.py # 投资组合API
│   │   └── deps.py          # 依赖注入
│   ├── core/                # 核心配置
│   │   ├── config.py        # 配置文件
│   │   ├── security.py      # 安全相关
│   │   └── database.py      # 数据库配置
│   ├── models/              # 数据模型
│   │   ├── stock.py         # 股票数据模型
│   │   ├── user.py          # 用户模型
│   │   └── analysis.py      # 分析结果模型
│   ├── services/            # 业务服务
│   │   ├── stock_service.py # 股票数据服务
│   │   ├── ai_service.py    # AI分析服务
│   │   └── data_service.py  # 数据获取服务
│   ├── utils/               # 工具函数
│   └── main.py              # 应用入口
├── tests/                   # 测试代码
├── alembic/                 # 数据库迁移
└── requirements.txt         # 依赖包
```

### 3.3 核心服务模块
- **数据获取服务**：股票数据API集成、数据清洗处理
- **AI分析服务**：Claude API集成、分析逻辑封装
- **用户服务**：用户认证、权限管理、偏好设置
- **缓存服务**：数据缓存、分析结果缓存

## 4. AI服务架构

### 4.1 Claude Agent设计
```
Claude Agent
├── 基本面分析引擎
│   ├── 财务指标计算
│   ├── 估值模型分析
│   └── 行业对比分析
├── 技术面分析引擎
│   ├── 价格走势分析
│   ├── 技术指标计算
│   └── 交易量分析
├── 风险评估引擎
│   ├── 市场风险分析
│   ├── 流动性风险评估
│   └── 波动率分析
└── 推荐引擎
    ├── 个性化推荐
    ├── 投资策略建议
    └── 买卖点提醒
```

### 4.2 AI服务特点
- **多模态分析**：结合数值数据和文本信息
- **实时处理**：支持实时数据分析和响应
- **个性化**：基于用户画像的定制化分析
- **可解释性**：提供分析逻辑和依据说明

## 5. 数据架构

### 5.1 数据源
- **股票基础数据**：股票代码、名称、行业分类
- **财务数据**：资产负债表、损益表、现金流量表
- **市场数据**：价格、成交量、技术指标
- **宏观数据**：经济指标、行业数据、政策信息

### 5.2 数据流向
```
外部数据源 → 数据采集 → 数据清洗 → 数据存储 → 数据分析 → 结果展示
    ↓           ↓         ↓         ↓         ↓         ↓
股票API     定时任务    数据验证    数据库     AI分析    前端展示
```

### 5.3 数据存储
- **关系型数据库**：用户数据、基础数据、分析结果
- **时序数据库**：股票价格、交易量等时间序列数据
- **缓存数据库**：热点数据、计算结果缓存
- **文件存储**：分析报告、图表文件

## 6. 部署架构

### 6.1 开发环境
- **容器化**：Docker + Docker Compose
- **代码管理**：Git + GitHub
- **CI/CD**：GitHub Actions
- **监控**：本地日志

### 6.2 生产环境
- **云平台**：阿里云 / 腾讯云 / AWS
- **容器编排**：Kubernetes
- **负载均衡**：Nginx / ALB
- **数据库**：云数据库服务
- **监控**：Prometheus + Grafana
- **日志**：ELK Stack

### 6.3 安全架构
- **认证授权**：JWT Token
- **HTTPS**：SSL/TLS加密
- **API限流**：Rate Limiting
- **数据加密**：敏感数据加密存储
- **防火墙**：网络安全防护
